## 5. 미리 적는 해석 (기계 적용)

- **P1 ✅ ∧ P2 ✅** → "짝지은 고리 효과가 둘째 밀도의 진화 배경에서도 선다". P1 ✅ · P2 ❌ → "합쳐서는 서지만 짝 하나하나는 흔들린다(54 중 k)". P1 ❌ → "둘째 밀도에서 서지 않는다" — 원고 §3.2 의 일반성을 밀도 8 로 한정.
- **L1 ✅** → "사다리 반전이 둘째 밀도에서도 선다".
- **L1 ❌ 의 갈래 (R5 로 빈칸을 메움 · 결과 전 · 모든 경우를 덮는다)** — 먼저 Δ(0) 하한으로 나누고, 그다음 교차 점추정으로 나눈다:
  1. Δ(0) 하한 > 0 · 교차 점추정 **+∞**(1% 까지 +) → 반전이 측정 범위 밖으로 밀려난 것. 예측 1 과 같은 쪽이므로 "반전이 사라졌다" 로 쓰지 않고 "**1% 안에서는 뒤집히지 않는다**" 로 쓴다. L2 는 기계 적용하되 `cens_hi`(재추출 중 ∞ 비율)를 함께 적는다.
  2. Δ(0) 하한 > 0 · 교차 점추정 **유한**(1% 안) · Δ(1%) 상한 ≥ 0 → "**반전 점은 있지만 1% 에서의 해로움이 구간상 서지 않는다**" · 교차 값은 서술. L2 는 기계 적용하되 `cens_hi` 를 함께 적는다(∞ 재추출이 섞이면 '위로' 쪽 확률이 검열에 기댄다).
  3. Δ(0) 점추정 > 0 · 하한 ≤ 0 → "**속도 이점이 구간상 서지 않는다**". L2 는 계산하되 `cens_lo`(재추출 중 검열 0 비율)를 함께 적는다. `cens_lo` ≥ 0.025 인데 L2 ❌ 아래로면 그 방향은 검열 0 에 기댄 것이므로 원고에는 서술로만 쓴다.
  4. Δ(0) 점추정 ≤ 0 → "**속도 이점부터 서지 않는다**" — 교차 점추정이 검열 0 이므로 L2 방향 해석은 원고에 서술로만.
- **L2 ✅ 위로** → 예측 1 확인 · 원고 §3.7 끝 문단("교차가 움직인다")에 둘째 축(밀도)을 더할 근거. **L2 ❌ 아래로** → 예측 반대 — §3 의 반대쪽 증거(진화 공동체가 부족을 되살림)를 서술로 붙이고, 조작 확인(R)이 실제로 줄었는지 함께 적는다. **L2 🟡** → "교차가 밀도 8 과 **구별되지 않는다**(차 d 의 95% 구간 [a, b]%p)" — 구간을 반드시 함께 적는다. '같은 자리' · '같다' 로 쓰지 않는다(R2 · 동등성 한계를 미리 정하지 않았다). 서술로만: d 상한 < +0.037%p(= §3 띠 하단 0.21% − 밀도 8 0.173%)이면 "§3 수치 예측의 하단이 배제된다" 를 덧붙일 수 있다. 🟡 는 배경 20 대 60 에서 가장 나올 법한 갈래다(파일럿 배경 2 에서도 🟡 · 해부 21 묶음 차 구간 폭 약 0.045%p).
- **조작 확인 규칙 (R4 · 서술 규칙 · 🟡 파일럿 뒤 · 본 데이터 전에 고정)**: 배경마다 `racld` 의 `n` 삽입 여섯 코드의 ln R(시도/성공) 평균 → 밀도 D(20)와 밀도 8(해부 15 Eib 20) 각각 배경 재추출 2,000(독립) → 차 d_R = D − 8 의 95% 구간으로 셋:
  - 상한 < ln 0.5 → "**§3 전제만큼 줄었다**"(0.5 = §3 크기 근거의 기울기 비 0.27~0.5 중 큰 쪽 · 결과 전 숫자) — L2 를 "부족이 덜한 세계" 의 결과로 읽어도 된다.
  - 상한 < 0 → "**줄었지만 §3 전제(비 ≤ 0.5)에 못 미친다**"(비 e^d_R 를 함께 적는다) — L2 를 "부족이 덜한 세계" 로 읽지 않는다.
  - 그 밖 → "**줄지 않았다**" — L2 를 "부족이 덜한 세계" 로 읽지 않는다.
  - 앞 둘이 아닌 경우 L2 는 "같은 규칙 · 다른 밀도의 진화 배경" 결과로만 쓴다. 판정기가 이 규칙을 그대로 인쇄한다(`manip.lnR_rule`).
  - (R12) 이 실험에서는 '부족이 덜한 세계' 로 읽지 않는 갈래가 적용될 가능성이 높다 — 파일럿(배경 2)에서 이 규칙은 d_R −0.123 [−0.138, −0.107] · 비 0.88 → "줄었지만 §3 전제에 못 미친다" 였다(`_RESULT_pilot25r.txt:189`).

## 6. 정직한 한계 (미리 박음)

- **밀도는 하나**다. 방향이 맞아도 '밀도에 따라 단조' 는 말할 수 없다(점 둘).
- 배경은 '끝 우세 `racld`' 로 **골랐다** — 둘째 밀도의 진화가 `racld` 를 덜 고른다면 자격 배경은 그 밀도의 대표가 아니라 `racld` 가 이긴 세계다(밀도 8 도 같은 규칙이지만 자격 비율이 다르면 선택 강도가 다르다). 파일럿 · 본 성장의 자격 비율을 같이 적는다.
- 교차는 8 점 곡선의 보간이고, 이 실험은 범위 밖을 검열로 다룬다. 교차가 1% 를 넘으면 '얼마나 위' 인지는 모른다.
- 교차 비교는 **배경이 다른 두 묶음**(밀도 D 20 · 밀도 8 60)의 비교다 — 배경 짝이 없다. 밀도 효과와 '다른 시드' 효과를 가를 수 없다(밀도 8 안에서 해부 6C 20 대 해부 21 40 의 차가 −0.013%p [−0.037, +0.009] — `_RESULT_inv21.txt:32` · 그 정도가 시드 묶음의 흔들림이다).
- 짝 크기 비교(P4)도 배경이 다른 두 묶음이다.
- 조작 확인은 `racld` 다섯 코드의 R 뿐이다 — 씨앗의 부풀림은 직접 재지 않는다.
- 🟡 동시 실험: 해부 24 가 같은 서버에서 ≤ 12 병렬로 돈다. 시드 범위를 미리 알 수 없다 — 2501~2550 이 겹치면 실험 사이 독립성만 문제다(이 실험의 타당성엔 영향 없음). 발사 전 서버 `find` 로 다시 확인한다. (R7) 두 발사기는 발사 순간 다른 node 수 + 병렬 ≤ 36 을 확인하고 로그 둘째 줄에 적는다 — 발사 뒤 해부 24 가 늘리는 것은 막지 못한다.
