**배경 · 침입 절차**(원고 §5.1 의 말을 옮김):
- 배경: 상주(L = 4) 100 개체에서 시작 · **μ = 0** · 6,000틱(평균 수명의 약 13 배) 성장. 자격 = 멸종 없음 · 끝 개체 수 ≥ 50.
- 침입: 배경 상태를 복제 → 산 개체의 10%(반올림)를 끼운 코드로 바꾼다(재료 보존: 바뀐 개체의 글자 · 만드는 중인 자식 글자를 풀로 돌리고 새 코드 글자를 풀에서 가져옴 · 못 하면 되돌리고 건너뜀 · 셈). 바꿀 개체는 (seed, ρ, 'inject') 흐름으로 골라 **모든 팔 · μ · 규칙에서 같다**. → 3,000틱 · 250틱마다 기록.
- 팔: (규칙 2) × (μ 8) × (끼운 팔 `mut`(L = 2) 1 + 기준 팔 `ref0~4`(L = 4) 5) = 배경당 **96 팔**. 원고는 기준 11 개 — 계산 때문에 5 로 줄였다(§6).
- 지표(꼴은 `inv21_analyze.py:65-69` 그대로): s = ln((m_T + 0.5)/m_0) − ln((n_T − m_T + 0.5)/(n_0 − m_0)) · m = 끼운 계통(혈통으로 · 불임 자손 포함) · n = 산 개체 전부 · **Δ = s(mut) − 기준 다섯 s 평균**. 교차 = 평균 Δ 곡선의 첫 + → ≤ 0 부호 변화의 선형 보간(`:120-125`).
- R = 추첨 수 ÷ 완료 위치 수(빠뜨림 · 바꾸기 · 옳음은 위치를 넘기고, 끼우기는 안 넘긴다) — 끼운 팔 안에서 계통 · 고리별로 센다(`1_2` = 끼운 계통 짧은 고리 · `0_4` = 배경 계통 상주). T/R = 시도당 틱(구현이 L 을 지키는지 · 서술). I = 실현 오류 ÷ 완료 위치 ÷ μ(서술).

**조용한 실패 가드**(코드 안 · 판정기 G0):
1. **재료 보존 재계수** — 계수기를 믿지 않고 250틱마다 · 시작 · 끝에 구조에서 다시 센다: 자유 + Σ 몸 + Σ 자식 글자 = M · 점유 = 개체 + 잡은 자식 자리 ≤ K · 자유 ≥ 0 · 자리 없는 자식 글자 0. 위반은 파일에 남고 판정기가 멈춘다. **음성 대조(10-02 · 버리는 사본)**: 죽을 때 자식 글자를 안 돌려주게 한 사본은 첫 검사(t = 250)에서 `글자 합 2368 != 2400` 으로 잡혔다.
2. **μ = 0 규칙 동일성** — 흐름 이름에 규칙이 없고 추첨 흐름이 따로라, μ = 0 에서 roll-first · find-first 의 개체 수 궤적과 완료 위치 수가 **바이트 단위로 같아야** 한다(배경 × 팔 6 전부). 다르면 규칙 말고 다른 것이 갈린 것 → 멈춘다. ⚠ (검토 N1) 이 가드는 **누수 점검**이지 규칙 구현이 맞는지에 대한 점검이 아니다 — μ = 0 이면 roll 의 추첨은 결과에 닿지 않으므로 구성상 통과한다. 두 규칙이 μ > 0 에서 맞게 갈리는지는 서술 칸 R 사다리(find 의 R 은 멈춤이 추첨을 안 써서 ≈ 1 · roll 은 > 1)로만 본다. 계수기 **키 집합**이 같은지도 본다(N3).
3. **멸종 처리** — 배경 멸종 · 끝 개체 < 50 → 자격 없음(시드 순으로 다음 후보). 팔에서 **개체 전체가 전멸**하면 그 배경을 그 (ρ, 규칙, μ) 칸에서 빼고 센다 · 판정 칸에서 뺀 배경 > 2 → 그 칸 판정 불가(**검토 M1 로 판정에 실제로 닿게 했다** — §4 '판정 불가 전파'). **끼운 계통만 소멸**한 것은 빼지 않는다(m_T = 0 은 +0.5 보정으로 지표에 그대로 들어간다 · 원 판정기와 같음) · 수를 인쇄.
4. **시드 키** — 판정 후보 26001~26030 · 파일럿 26901~26910. 발사기와 판정기가 섞임을 거부한다.
5. **재현** — 판정 뒤 (ρ 8 · 32) × 시드 26001 을 다른 디렉터리에 다시 돌려 시간 칸을 뺀 JSON 이 같아야 한다(`judge --repro` · 검토 개정 뒤 **필수** — 없으면 G0 가 멈춘다).
7. **끼우기 동일성**(검토 S6) — 한 배경 안 96 팔은 같은 스냅숏 · 같은 'inject' 흐름이므로 (n_inject, skipped) 가 모두 같아야 한다(G0). 판정 출력에 ρ 마다 끼운 개체 수 범위 · 건너뜀 합을 인쇄한다.

## 3. 무엇을 묻나 · 미리 적는 예측 (Claude · 결과 전 · 10-02)

**질문**: 원 시뮬레이터 코드 없이, 가정 1(재료 보존 + 멈춤)과 가정 2(roll-first)만 담은 최소 모형에서 원고의 핵심 결과가 **정성적으로** 다시 나오나. 그리고 그 결과가 **가정 2 를 빼면(find-first)** · **가정 1 의 멈춤을 거의 없애면(풍부)** 사라지나.

> [!warning] 검토 M2 (10-02 · 결과 전) — 무엇이 정보이고 무엇이 아닌가
> **P2 · P3 · P4a 는 이 모형에서 구조상 거의 참이다. 정보는 P1(크기: 1% 안에서 반전이 일어나나)과 P4b((R − 1)L 불변)에 있다. P2 · P3 는 증거가 아니라 모형 일관성 점검이다.**
> 이유(`mini26.py` 를 다시 읽고): L 이 오류 비용에 닿는 경로는 '멈춘 시도의 추첨'(R) 하나뿐이다. find-first(`mini26.py:225-228`)에서는 두 고리의 위치당 추첨이 ≈ 1 로 같고, 두 종의 글자열도 같으므로(`:57`) 자식이 불임이 될 확률이 L 과 무관하다 → Δ(0) > 0 이면 Δ 가 1% 안에서 부호를 바꿀 경로가 사실상 없다(c_ff = +∞). 풍부 쪽은 파일럿에서 멈춤 비 0.000 · R 1.00(`petri/_RESULT_pilot26.txt:3`)이라 roll ≡ find 에 가깝고, 조작 확인(풍부 R ≤ 1.1)의 통과가 곧 P3 ✅ 와 거의 같은 뜻이다. P4a 도 전역 가뭄에서 L2 가 두 배 자주 두드리므로(R − 1 ≈ D/L) 거의 정의상 참이다. P1 의 **방향**(μ 0 우위와 roll-first 반전)도 가정을 고를 때 기제로 이미 들어가 있다 — 실제로 시험되는 것은 **크기**, 곧 전역 가뭄에서 생기는 R 차이가 1% 안에서 μ 0 우위를 뒤집을 만큼 큰가이다.
> 아래 확신 숫자(결과 전에 적은 값)는 지우지 않고 그대로 두되, P2 · P3 · P4a 에는 '구조상' 꼬리표를 단다.

**미리 적는 범위**: 최소 모형은 **정량 일치를 목표로 하지 않는다**. 교차 μ 의 수치가 0.18% 와 맞는지는 **판정하지 않는다**(서술). 공간 · 수명 분포 · 코드 · 불임 규칙이 다 달라 수치가 맞을 이유가 없다.

**P1 — roll-first · 희소에서 μ = 0 의 짧은 고리 우위와 반전이 함께 선다** (확신 약 60%).
- μ = 0 에서 Δ > 0(짧은 고리가 같은 결핍 동안 더 자주 풀을 두드려 돌아온 글자를 먼저 가져가고, 멈춤 밖의 시간도 짧다) · μ 가 커지면 짧은 고리가 시도마다 추첨해 오류(→ 불임 자식)를 더 많이 받아 부호가 바뀐다.
- 🟡 불확실한 곳: 최소 모형의 불임 규칙(오류 하나 = 불임)은 접시보다 가혹할 수도, 접시의 공간 결핍보다 전역 결핍이 약해 R 이 작을 수도 있다. 반전이 1% 안에 안 들어오면 P1 ❌ — 그것도 정보다(§5).

**P2 — find-first 에서는 교차가 사라지거나 크게 밀린다** (확신 약 80% · 🔧 **구조상** — 모형 일관성 점검, 증거 아님 · 검토 M2). find-first 는 두 고리의 R 을 모두 ≈ 1 로 만들어 위치당 오류가 같아지므로, 오류 비용이 고리 사이에서 거의 같다. 남는 것은 걸러짐(바꾸기 글자가 없으면 멈춤)의 작은 차이뿐.

**P3 — 풍부한 재료(roll-first)에서 교차가 사라지거나 크게 밀린다** (확신 약 75% · 🔧 **구조상** — 조작 확인 통과와 거의 같은 뜻 · 증거 아님 · 검토 M2). 멈춤이 드물면 R ≈ 1 → 같은 이유. 🟡 풍부에서는 자리(K)가 한정 자원이 되어 μ = 0 우위 자체가 작아질 수 있다 — 그 경우에도 '교차 없음' 쪽이면 P3 ✅ 이고, Δ(0) ≤ 0 이면 검열 교차가 0 이 되어 P3 는 '남음' 쪽으로 잡힌다(§4 정의 · 보수적).

**P4 — R 은 짧은 고리에서 크고, (R − 1) × L 은 고리와 거의 무관하다** (P4a 확신 약 85% · 🔧 P4a 는 **구조상** · P4b 약 55% — 정보는 P4b 에 있다 · 검토 M2).
- 근거: 결핍이 **틱 단위로 이어지는 가뭄**이면(전역 풀이 0 이 되면 누군가 죽어 글자를 돌려줄 때까지 모두 기다린다), 가뭄 D 틱 동안 고리 L 은 약 D/L 번 두드린다 → 글자당 멈춤 틱 (R − 1)L ≈ D 로 L 과 무관(해부14 §9 A1b 의 기제 서술과 같은 꼴).
- 🟡 반대 경우: 시도마다 독립인 결핍이면 두 고리의 R 이 같고 (R − 1)L 비는 L 비 = **0.5** 가 된다. P4b 는 이 둘을 가른다.

🚫 이 노트 어디에도 '최소 모형이 접시를 재현했다(정량)' 를 쓰지 않는다. P1~P4 가 서도 결론은 "두 가정만으로 **같은 방향의** 결과가 나온다" 까지다. P2 · P3 · P4a 의 ✅ 는 그 결론의 **증거로 세지 않는다**(검토 M2).

## 5. 미리 적는 해석 (기계 적용)

- **P1 ✅ ∧ P2 ✅ ∧ P3 ✅** → "원고가 말한 기제를 원 코드 없이 구현해도 μ 0 우위와 1% 안의 반전이 같은 방향으로 나온다(**충분성**)". P2 · P3 ✅ 는 모형 일관성 점검으로만 덧붙인다(검토 M2 — 구조상 거의 참이라 증거로 세지 않는다). `sim.js` 가 다른 경로(버그 포함)로 같은 결과를 내는 것은 이 실험이 배제하지 못한다(§6). 원고에는 "a minimal model with only these two assumptions reproduces the direction" 까지만.
- **P1 ✅ · P2 ✅ · P3 ❌/🟡** → 추첨 위치(가정 2)는 필요조건으로 서지만 '재료 결핍' 쪽 설명은 이 모형에서 약하다. 배경 조작 확인(아래)이 ❌ 면 P3 는 '풍부' 의 결과로 읽지 않는다.

## 6. 정직한 한계 (미리 박음)

- **보조 가정 3(오류 = 불임)** 은 두 가정 밖의 것이다. 오류가 무해하면 반전은 정의상 안 생긴다 — 이 실험은 "오류가 비용이 있을 때, 그 비용이 고리에 따라 달라지는 것은 두 가정에서 나온다" 를 시험한다. 불임 대신 '느려짐' 같은 다른 비용은 시험하지 않는다.
- **전역 풀**: 공간이 없어 결핍이 전역이다. 접시의 결핍은 국소(이웃 다섯 칸)다. P4b 가 이 차이에 가장 민감할 것이다(§3).
